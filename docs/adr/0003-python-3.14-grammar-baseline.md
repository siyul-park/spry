# 0003: Python 3.14 grammar baseline

- Status: Accepted

## Context

The AST and parser need a single grammar target, and conformance needs a single oracle. Python 3.14 includes PEP 695 type parameters, PEP 701 f-strings, PEP 750 t-strings, `match`, and `except*`.

## Decision

The grammar baseline is Python 3.14 (`Grammar/python.gram`, `Parser/Python.asdl`). The `ast` package mirrors CPython 3.14 `ast` 1:1. The oracle is `python3.14`; `ast.Dump` must equal `ast.dump(tree, include_attributes=True, indent=1)` on the corpus. The `-V` output reports `Python 3.14.0`.

## Consequences

- Goldens are generated by one CPython version; a CPython patch release that changes `ast.dump` output is detected by a CI drift job.
- Newer-version syntax is rejected with CPython's error until the baseline moves via a new ADR.
- Contributors need Python 3.14 only to regenerate goldens.

## Alternatives

- Track the latest CPython: moving target, goldens churn.
- Older baseline (3.12): lacks t-strings and 3.14 behaviors users now expect.
- Own AST shape: cheaper to write but loses the mechanical correctness check against CPython.
