# Architecture Decision Records

MADR format. Each record has Status, Context, Decision, Consequences, Alternatives. Decisions that can be checked mechanically (dependency rules) are mirrored as lighthouse decisions (ADR 0005). To change a decision, add a new ADR that supersedes the old one.
